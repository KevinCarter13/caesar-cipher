# 🔐 Caesar Cipher Tool

A beautiful, responsive web-based Caesar Cipher encoder/decoder with Brute Force attack.

## Features
- 🔒 Encode & Decode with custom shift (1-25)
- 💥 Brute Force - tries all 25 shifts and ranks by English word frequency
- 📊 Live alphabet mapping visualization
- 📋 One-click copy
- 🎨 Dark theme, fully responsive design
- ⌨️ Keyboard shortcut: Ctrl+Enter to process

## Tech
- Pure HTML/CSS/JavaScript - no dependencies
- Optimized char-code based cipher
- English frequency analysis for smart brute-force ranking
